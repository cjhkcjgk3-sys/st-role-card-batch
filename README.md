## 它做什么

在同一个回复楼层里按名单逐条生成角色卡，一条回复对应一个角色：

- **名单批量写卡**：每行一个角色名，按顺序生成，断点续传
- **运行中调整队列**：待生成角色可以置顶、长按拖动排序或暂移；暂移角色可从折叠区放回队尾，也可在运行中加入新角色。当前角色会先完成
- **等待与自动继续**：角色之间随机等待 5～20 秒，若“回复后等待”设置更长则按较长时间等待。生成超时、断线或酒馆退回旧候选页时，等待 20～30 秒，确认上一轮结束并核对结果后自动继续；累计中断或恢复失败 3 次后停止。手动停止和无法确认结果等其他情况不会自动继续
- **失败自动暂移与集中重跑**：单个角色生成失败、截断失败或「核对备选页」查出截断后，会自动记录原因并移入「暂移角色」区，继续生成后续角色；攒多后可一键「全部放回队列」再点「开始／继续」集中补齐，或「复制名单」到新聊天重跑
- **已完成角色名录**：生成成功自动收录，下一次自动跳过；删除名录项或清空名录会把关联批次项重新排队，不删除已有角色卡或回复。手动标失败会同步移出名录
- **作品图片库**：导入作品 ZIP（`00-角色清单.md` 加可选的 `01-皮肤清单.md`，也兼容旧的 `00-清单.md`），按角色名自动配图；从清单添加到名单时只展示本体角色，皮肤不加入名单
- **手动纠错与核对备选页**：支持手动标记完成 / 失败 / 恢复自动判断；可在生成设置中配置「最小 Token 数（防截断）」（如 5000），与流式中断、标签闭合、名称比对组成多层校验；点击「核对备选页」可一键扫描当前批次已有备选页，自动把截断或 Token 不足的页改标失败、移入暂移区并移出名录（不删除已有回复）
- **重生成确认**：候选版本先对比再决定是否替换

## 安装

1. SillyTavern → 扩展 → 安装扩展
2. 填仓库地址：`https://github.com/cjhkcjgk3-sys/st-role-card-batch`
3. 刷新页面，在扩展设置里打开「角色卡批量生成器」

需要 SillyTavern 1.14.0 以上（图片库依赖其发图接口）。

## 从旧插件升级

设置键仍是 `novel-auto-generator`，名单、名录、图片库和全部配置会直接沿用，**无需迁移**。切换时先停用旧版，再启用本插件并刷新页面；两个版本不能同时加载，因为它们会共用界面节点和生成拦截器。

## 使用流程

1. 在聊天里写好提示词楼层，保留 `[[角色名]]` 占位符
2. 把角色名贴进「角色名单」，每行一个
3. （可选）导入作品 ZIP，让每个角色自动带上立绘
4. 点「开始／继续」，一条回复一个角色
5. 生成有问题的角色在名单里手动纠错，或在名录里删除后重新生成
